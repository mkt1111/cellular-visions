# Cellular Visions

A visualizer for Wolfram's elementary (1D) cellular automata.

## Features

- Choose any rule from 0 to 255 via input or slider
- Visualization of the selected rule's 8 neighborhood cases
- Adjustable cell size, animation speed, maximum generations and zoom
- Selectable color modes

## Tech stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui (Radix UI)
- React Router
- TanStack Query
- lucide-react

## Running locally

Requires Node.js and npm.

```sh
npm install
npm run dev
```
